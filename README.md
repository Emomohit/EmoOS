# 💻 Emo OS

Welcome to **Emo OS**, a fully customized, dark-themed, and glassmorphic operating system built in React. Crafted by **Mohit**.

![Emo OS Wallpaper](./public/img/wallpaper/default/img0.jpg)

## 🚀 Features
- **Emo Branding:** Deep dark neo-cyberpunk aesthetics, featuring glowing neon violet, pink, and cyan accents.
- **Custom Apps:** Integrated with **EMOVibes** and **Emo-Links**.
- **Interactive Desktop:** Draggable windows, fully functional start menu, and taskbar.
- **Web-Based OS:** Runs completely in the browser! No installation required.

## 🛠️ Built With
- React 18
- Redux
- Vite
- Tailwind CSS

## 💻 Quick Start

To run Emo OS locally on your machine:

```bash
# Clone the repository
git clone https://github.com/Emomohit/EmoOS.git

# Navigate into the project
cd EmoOS

# Install dependencies
npm install

# Start the development server
npm start
```
Your personalized Emo OS will now be running at `http://localhost:5173`.
